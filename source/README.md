# 糟糕島物語 ～無名氏與最後的回應～

以 K 島（糟糕島）為舞台的網頁版 JRPG，用 C# / Blazor WebAssembly 寫成。

> 在資訊之海的正中央，漂浮著一座由「回應」堆成的島。島上沒有人需要名字，大家都叫彼此「無名氏」。
> 這座島被爆破過很多次，每一次都有人把它一串一串地重建起來。然而這一次——島，開始沉了。

## 執行方式（Visual Studio 2022）

1. 在 Visual Studio Installer 勾選「**ASP.NET 與網頁程式開發**」（附帶 .NET 8 SDK）。
2. 解壓縮後雙擊 `KomicaRPG.sln`。第一次開啟會自動還原 NuGet 套件（需要網路）。
3. 按 **F5**，瀏覽器會自動開啟遊戲。

> 如果你的電腦只有較新的 .NET SDK，可以把 `KomicaRPG.csproj` 的 `net8.0` 和套件版本改成對應的版本。

## 操作

| 按鍵 | 功能 |
|---|---|
| 方向鍵 / WASD（或畫面上的十字鍵） | 移動、選擇；按住不放會連續移動 |
| Enter / 空白鍵 / Z | 調查、對話、確認 |
| Esc / X | 打開選單、取消 |
| F（或標題下方的「全螢幕遊玩」） | 全螢幕；手機上按鍵會半透明疊在畫面上，右上角按鈕離開 |

野外的怪物是**明雷**：地圖上看得到，碰到才會開戰，可以繞路躲開，靠太近會追過來（發紅光）。打贏的怪在離開地圖前不會再出現；用「無視」逃走後，那隻怪會暫時不追人。因為可以躲，打到的每一場經驗值與 K 幣是原本的 1.8 倍。

島上的名人也在遊戲裡（以島上流傳的梗為靈感的虛構角色，劇情與台詞皆為創作）：
- **生日哥**（綜合村）：支線「今天我生日ㄛ」，向島上名人收集 4 張祝福卡，幫他辦一場真正的生日派對。
- **照燒貓**（跟著劇情在各地擺攤）：賣照燒料理、講島的歷史；支線「照燒的祕方」找回 3 個祕方材料。
- **智障神**（新番鎮）：每天洗開箱文的「開箱之神」，可以挑戰的隱藏魔王，打贏後的選擇會改變他。
- 易經廚（綜合村，會幫你卜出目前的目標）、放矢哥、西瓜哥、塗鴉廚，以及討論板上的各種武將與廚。

開新串時可以選**難度**，之後也能在「設定」切換（跟著存檔記錄）。簡單模式：敵人 HP 7 成、受到的傷害 6 成、經驗值與 K 幣 1.5 倍、「無視」一定成功、怪物比較少也不太追人。

畫面下方的按鈕可以用滑鼠或手指點。進度在換地圖時自動存檔，也可以在選單裡手動存檔（存在瀏覽器的 localStorage）。

## 遊戲內容

- **6 章、14 張地圖**：綜合村、新手串原、沉船灘、捏他平原、新番鎮、捏他之森、惡搞谷、釣魚港、掛圖美術館（2 層）、實名要塞（2 區）、精華區深淵、主機之心。
- **4 人隊伍**：無名氏（平衡型）、莎吉（sage 術士，攻擊魔法）、阿梗（梗王，回復與輔助）、戴爾（刪文騎士，坦克）。每人約 6～7 個隨等級習得的技能。
- **戰鬥系統**：依速度排序的回合制、5 種屬性弱點（炎上／冷場／暴雷／神串／黑歷史）、異常狀態（炎上、sage、被釣、潛水、攻防增減、挑釁、誘餌、404）、防禦、道具、逃跑。魔王會預告大招，每隻都有自己的機制。
- **裝備與商店**：武器／防具／飾品三格，商店會顯示每位隊員換上後的數值變化。
- **9 場魔王戰 + 1 隻隱藏魔王**。
- **6 個支線任務**：走失的喵咪、外來種、剪掉名牌、古串碎片、被實名的島民、沉船之主。
- **3 種結局**：你在劇情中的幾個選擇，會決定最後的結局。做出選擇時，畫面會悄悄提示「有人推了你一下」。
- **推量表與合體技**：攻擊、打中弱點、受傷、防禦都會累積「推」，滿了可以發動「神串降臨」（全體神串傷害）或「全島推爆」（全隊回復與強化）。
- **弱點發現與怪物圖鑑**：用屬性打中弱點會自動記錄，選擇目標時會顯示已知弱點；圖鑑收錄 33 種怪物。
- **島內討論板**：每個城鎮和迷宮都有一塊 K 島風格的討論板（無標題／無名氏／ID／綠字引用），貼文會隨劇情更新，藏著攻略提示，還有一個 ID 永遠是 ???????? 的可疑貼文者。
- **隊伍聊天**：12 段隨劇情解鎖的角色對話，在選單「聊天」裡看。
- **章節標題卡、跳串（快速傳送）、戰鬥速度設定、自動戰鬥、傷害數字**。

## 專案結構

```
KomicaRPG/
├─ Engine/
│  ├─ GameData.cs       game.json 的資料模型
│  ├─ Units.cs          隊員、敵人、選單、存檔等類別
│  ├─ Game.cs           狀態、數值、劇情腳本、地圖、存檔、輸入
│  ├─ Game.Menus.cs     地圖選單與商店
│  └─ Game.Battle.cs    回合制戰鬥
├─ Pages/GameView.razor 畫面（只負責顯示，邏輯都在 Engine）
└─ wwwroot/
   ├─ data/game.json    所有關卡、劇情、怪物、道具資料
   ├─ img/              像素素材（16×16 繪製，輸出 48×48）
   └─ css/game.css
tools/
├─ content_db.py        角色、技能、道具、怪物、商店、任務的數值
├─ content_extra.py     討論板貼文、隊伍聊天、章節、跳串地點
├─ build_content.py     地圖與劇情腳本；執行後產生 game.json，並自動檢查座標與可達性
├─ make_assets.py       重新產生所有像素圖（需要 Python + Pillow）
├─ sim.js               戰鬥平衡模擬器（需要 Node.js）
└─ render_maps.py       把地圖畫成圖片預覽
web/                    同一份資料的 JavaScript 版本（網頁預覽用）
```

## 修改內容

所有關卡和劇情都在 `wwwroot/data/game.json`，C# 程式不用改。建議改 `tools/` 裡的 Python 原始檔再重新產生：

```
cd tools
python build_content.py ../KomicaRPG/wwwroot/data/game.json
node sim.js ../KomicaRPG/wwwroot/data/game.json      # 調整數值後檢查難度
```

劇情腳本是簡單的指令陣列，例如：

```python
say("綜合伯", "第一句", "第二句"),          # 對話
IF("flag:boss1", [...], [...]),              # 條件分歧
choice(("選項 A", [...]), ("選項 B", [...])),  # 玩家選擇
battle("boss1"), give("noodle", 3), F("flagName"), goal("新目標")
```

## 素材

`wwwroot/img` 的圖全部由 `tools/make_assets.py` 用程式畫出，是原創素材，可以自由使用和修改。想換成更精緻的免費素材（例如 Kenney 的 CC0 素材），用相同檔名覆蓋即可。
